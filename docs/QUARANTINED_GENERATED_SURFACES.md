# Quarantined Generated Surfaces

The original application contains generated routes, direct chat completions, simulated planning features, unauthenticated permit access, runtime ORM synchronization, gap modules, and unsafe startup behavior. The client still includes prototype pages for some of them. They are not supported legal/compliance behavior.

The former `gapNoConversationalPlanningCopilotForCitizensOrOfficials.js` is superseded by durable matter-scoped conversations whose replies are deterministic summaries of a reviewed analysis, cite authorized sources, preserve redaction, display a non-advice boundary, and abstain without evidence. Reintroducing any quarantined route requires authoritative sources, jurisdiction/effective-date logic, matter permissions, qualified review, explicit failure semantics, and equivalent acceptance tests.
